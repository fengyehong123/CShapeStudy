# 一. 隐式 using
在 .NET 6 及以上版本（包括 .NET 8） 中，默认开启了 隐式 using（Implicit Usings） 功能，
所以像 
+ using System;
+ using System.Collections.Generic; 

这些常见命名空间不需要手动写也能直接使用。

在 .csproj 文件中，有一个设置项：
```xml
<PropertyGroup>
  <ImplicitUsings>enable</ImplicitUsings>
</PropertyGroup>
```
+ ✅ enable（默认） → 自动添加常用 using
+ ❌ disable → 需要你手动写出所有 using

# 二. 顶层语句（Top-level statements）
+ 在 C# 9 引入、并在 .NET 6+（含 .NET 8） 中默认启用的一个特性
+ 顶层语句就是让你在没有 Main 方法、没有类的情况下，直接写代码。

例如
```csharp
Console.WriteLine("Hello, World!");
```
🧠 适用场景
+ ✅ 简单脚本、控制台测试代码、示例程序、教学演示
+ ❌ 不推荐用于大型项目或库文件（因为失去清晰的结构）

# 三. 集合表达式（Collection expressions）
+ C# 12（随 .NET 8 一起发布）中新引入的特性
+ C# 12 起，可以用类似数组字面量的语法 [] 来直接创建各种集合（不仅仅是数组）。
```csharp
// 创建数组
string[] arr = ["a", "b", "c"];
int[] nums = [1, 2, 3];

// 创建List
List<int> list = [1, 2, 3];

// 混合已经有的集合
int[] a = [1, 2];
int[] b = [3, 4];
int[] all = [..a, ..b, 5];
```
