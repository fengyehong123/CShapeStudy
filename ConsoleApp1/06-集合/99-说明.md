# 1. 集合的分类
## （1）非泛型集合（在 System.Collections 命名空间里）
早期的集合，存储的是 object，类型安全性差，需要装箱/拆箱。常用的有：
+ ArrayList：类似动态数组，可以存放任意类型（性能不如泛型 List<T>）。
+ Hashtable：键值对存储，键和值都是 object。
+ Queue：先进先出（FIFO）队列。
+ Stack：后进先出（LIFO）栈。

## （2）泛型集合（在 System.Collections.Generic 命名空间里）✅推荐使用
类型安全、性能更好，最常用的集合类型：
+ List<T>：动态数组，支持索引访问。
+ Dictionary<TKey, TValue>：键值对映射。
+ Queue<T>：先进先出队列。
+ Stack<T>：后进先出栈。
+ HashSet<T>：不允许重复元素的集合。
+ SortedList<TKey, TValue> / SortedDictionary<TKey, TValue>：有序字典。

## （3）并发集合（在 System.Collections.Concurrent 命名空间里）
线程安全，适合多线程环境：
+ ConcurrentDictionary<TKey, TValue>
+ ConcurrentQueue<T>
+ ConcurrentStack<T>
+ BlockingCollection<T>

## （4）不可变集合（需要安装 System.Collections.Immutable 包）
线程安全，不可变（修改会生成新集合）：
+ ImmutableList<T>
+ ImmutableDictionary<TKey, TValue>
+ ImmutableHashSet<T>

# 2. 集合的选择
| 使用场景                    | 推荐集合                                   |
| :---------------------------| :------------------------------------------|
| 动态数组，需要频繁索引访问  | `List<T>`                                  |
| 键值对存储                  | `Dictionary<TKey, TValue>`                 |
| 不允许重复的集合            | `HashSet<T>`                               |
| 队列（FIFO）                | `Queue<T>`                                 |
| 栈（LIFO）                  | `Stack<T>`                                 |
| 多线程安全                  | `ConcurrentDictionary<TKey, TValue>` 等    |
| 数据不可修改                | `ImmutableList<T>` 等                      |


# 3. 总结
+ 一般情况下，优先使用泛型集合（List<T>、Dictionary<TKey,TValue> 等）。
+ 非泛型集合几乎已经被淘汰，只在老代码里会遇到。
+ 多线程环境用 并发集合，需要不可变数据时用 Immutable 集合。
